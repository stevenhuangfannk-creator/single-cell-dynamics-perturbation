# 图件自检 / Figure QA

图的共同目的：展示 SPI1 的正目标出边增强在真实 CD14+ Monocytes 推断网络中的后果，并将计算假设、数值剂量和统计响应分开说明。图形属于 quantitative grid / 网络比较；图 05 为强度敏感性主证据，图 06–09 为比较与响应解释。

全部图为 Python matplotlib 重绘，白底，PNG 600 DPI，PDF/SVG 可编辑文本；source-data CSV 由 manifest 一一对应。没有图用 KO 专用方向预测假装 OE 上调/下调。网络圆形位置为显示布局，非实际细胞坐标。所有页脚保留第三方实际方法与来源。
