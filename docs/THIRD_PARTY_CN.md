# 软件来源与使用边界 / Third-party provenance

本仓库的分析包装器调用第三方软件，不将这些软件的作者、许可或验证结论转移到本项目。安装时应按环境文件和模块记录的版本/源码 SHA 获取软件，并读取原项目许可。

| 来源 | 使用方式 | 注意事项 |
|---|---|---|
| scTenifoldKnk / scTenifoldNet | 官方 R 包及固定版本组件 | 2.0 行为与早期论文/1.x API 有差异，具体功能由实际安装版本与源码确定 |
| virt_overexpression / virt_knock | Experimental 的实际公开低层函数 | 未证实存在独立官方 scTenifoldOE；许可标记、实际 LICENSE、维护和测试状况见 OE 审查报告 |
| scTour | 官方包的训练、预测、向量场投影 API | 对其 Torch/Scanpy 环境单独锁定；原始 Figure 2 仅作本地视觉核查，输出均由新推断结果绘制 |
| 10x / GEO 公开数据 | 原始 counts 与来源 metadata 下载后登记 | 不转移数据所有权；引用原研究，记录过滤规则与校验值 |

第三方 OE 的标签与代码可能对边方向给出不同描述，应以矩阵构建、转置和实际改动核对，不能照搬名称作生物学结论。不同框架的网络降噪与对齐实现也不自动等价。没有独立实验对照的 KO/OE 比较用于方法审查与假设生成。

本项目未上传用户 PI/Healthy 私有数据。公开结果的开放许可不由本文件另行授予；Private 仓库保持私人访问范围。
