# 方法比较与解释边界 / Method comparison

| 方法 | 核心对象 | 输入 | 主要结果 | 核心边界 |
|---|---|---|---|---|
| scTenifoldKnk | WT 与删除靶基因出边后的 GRN | 同细胞类型原始 counts | 调控距离、FC、p 值、版本支持的方向 | FC 是距离的统计比值，不能标成表达 log2FC；方向预测另有假设 |
| Experimental OE | 实际第三方实现增强后的 GRN | 同一 WT 网络及其输入 | OE 距离、网络变化、强度敏感性 | 必须按真实源码说明增强边的方向与条件；增强倍数不等于表达倍数 |
| scTour | VAE 与神经 ODE 潜空间动力学 | 适当表达矩阵；NB 用原始 counts | Pseudotime、latent、向量场、嵌入 | 无需 spliced/unspliced；静态数据预测不能证明真实谱系转化 |

scTenifoldNet 提供网络构建与比较组件，不能仅因使用它就称为经过实验验证的 OE。scTour 的高维向量场须按官方邻域投影到嵌入；取 `X_VF[:, :2]` 贴到 UMAP 是错误坐标解释。对时间反向的修正须以外部生物学顺序为依据，并保存修正前结果。

## 运行状态 / Status semantics

- `RUN_OK`：指定配置的软件计算与输出检查通过；不自动等于论文或生物学验证成功。
- `REPRODUCED`：指定参考、数据、参数及目标结果有证据支持复现；应注明计算/趋势/视觉各层面的范围。
- `PARTIAL`：已有真实结果，仍有未完成面板、参数差异或稳定性限制。
- `BLOCKED`：具体外部或环境条件阻止该项计算；保留错误与尝试记录。

Smoke Test、模拟软件测试、真实公开数据及论文复现分别登记。未完成项不生成占位结果图；没有显著通路时仍保留完整统计表并如实报告。
